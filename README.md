# Portafolio de Algoritmos en PSeInt - Módulo de Algoritmia

Este repositorio recopila una serie de soluciones algorítmicas desarrolladas en **PSeInt**, abarcando desde estructuras secuenciales básicas y condicionales lógicas hasta bucles avanzados (`Mientras`, `Para`, `Repetir`), validaciones de rangos y programación modular.

## 🛠️ Contenido del Repositorio

| Archivo | Descripción del Algoritmo |
| :--- | :--- |
| `CajeroParqueadero.psc` | Control de cobro, conteo de vehículos y suma de recaudación mediante bucle iterativo[cite: 10]. |
| `calificaciones.psc` | Estadísticas académicas de notas (promedios, máximas, mínimas y alertas de refuerzo)[cite: 11]. |
| `Factura.psc` | Arquitectura modular para cálculo de subtotal, impuestos y propinas[cite: 12]. |
| `ValidarPin.psc` | Sistema de autenticación de tarjeta con control de intentos y bloqueo de seguridad[cite: 13]. |
| `Piramide.psc` | Generación de patrones gráficos y figuras geométricas en consola usando bucles anidados[cite: 14]. |

## 🚀 Requisitos de Ejecución
* Tener instalado **PSeInt** (compatible con perfil flexible o estricto según la configuración del entorno).
* Abrir cualquiera de los archivos `.psc` y ejecutar el intérprete paso a paso o de forma directa.
